`main.py` writes one line — a museum placard for an ordinary office object
treated as an ancient artifact — to `/output/entry.txt`:

> Votive sticky note, c. 900 BCE. Papyrus and optimism. 'Call back re:
> grain.' The call was never made. Bequest of an unknown intern.

131 characters, inside the 180-character limit. Run with `python3 main.py`.
